# 树成林 AI 产线剧场 · remake-v2

这是吴越做的 `remake-v2` 版本，不是原来的 `shuchenglin-handbook.pages.dev`。

## 在线入口

GitHub Pages 启用后，打开仓库 Pages 根链接即可进入新版。根目录 `index.html` 会自动跳到：

```text
remake-v2/
```

## 本地预览

```bash
npm run start
```

然后打开：

```text
http://127.0.0.1:4173/remake-v2/
```

## 主要入口

- `remake-v2/`：新版主站
- `game/`：树苗星球冲刺小游戏
- `original-index.html`：原开源包主站壳备份
