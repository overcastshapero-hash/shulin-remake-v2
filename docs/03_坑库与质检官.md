# 03 · 坑库与质检官(错误的复利 + 缺失的那道审美闸门)

## 一、坑库(每条都真实流过血;新窗口开工前必读,QA 断言含回归项)
**前端/GSAP**
1. 初始位移禁写 CSS transform——GSAP 解析成像素残留叠加在 yPercent 上,元素永久滑出遮罩;只准 gsap.set。
2. .fx-line 必须 inline-block,否则含内联子元素的行罩强制断行。
3. base.css `.fx-body img` 特异性(0,1,1)会压过单类选择器,需双类提级。
4. 同屏 live iframe ≤2,离场卸载杀音频;视频并发设上限管控器。
5. live 片自动放映=load 后静音全媒体+点片内播放键(播放键常晚绑定→延迟400ms+最多4次重试+"已在播"守卫)。
6. 嵌第三方整页:pointer-events:auto 才能交互;滚轮经 embed 模式回传父页;父页 ScrollTrigger 驱动 iframe 内部行程可找回其全部转场。
**多窗口协作**
7. fragment 头注里不许出现 `<section` 字样——总装按它截断会插进半截注释,产生幽灵元素+早产脚本(FX is not defined)。剥头注按目标类名或行级手术。
8. 并行窗口异步建段会持续改文档高度/章号:QA 必须等 scrollHeight 连续两次取样不变、滚动前现量 offsetTop、用类选择器不用 chap-XX id。
9. 重编号=id+data-chapter+chapnum+banner 四件同改,JS 永不硬编码章号。
10. 同一张任务卡绝不发两窗;E 窗发现撞车主动停手是正确行为,写进协议。
**QA/无头**
11. 预览工具窗口 hidden 时 rAF 冻结→动效页验证用 headless chrome;headless --screenshot 只拍文档顶部→用 puppeteer 滚动截图或 ?qa=1&scroll= 深链。
12. ?qa=1(跳loader关平滑)是 QA 生命线,每个新章都要支持。
**PowerShell/部署**
13. 命令文本含 `/E` `/*` `/1.25` 等会触发删除拦截器误杀整条命令——删文件单独跑;双引号串里 `\"` 不是转义(用反引号或 here-string);robocopy exit 1=成功。
14. 发布包重建必须重跑安全管线:robots+noindex头+terser 混淆自有JS+剥 HTML/CSS 注释(源码永远是明文,只处理 deploy 目录);增量部署靠哈希去重,改几个传几个。
15. 静态站对访客无完全保密;真要保密=换录屏或加访问门;注释里的战略信息是最大自泄露面。
**素材**
16. 截图文件名与画面大量错位——删丑按画面不按文件名(留素材核查映射表)。
17. 单文件 HTML 可能是空壳播放器(引用的 mp4 不在包里),入站前先验可运行。
18. 32MB"单文件版"=base64 内嵌,正则解包出 mp4/jpg 即可复用。

## 二、质检官(本次最大缺口的补法——审美闸门,今后每个交付物强制过)
**机制**:施工单元交付前,自动对自己产出截 5-8 张关键帧 → 由一个独立"质检官"代理(或自审)按下表打分 → **总分<8/10 不许交人,附问题清单自动重做一轮** → 人只终审 ≥8 分版本。
**评审表(用户钦定五问,各 2 分)**
1. 乔布斯会觉得好看吗?(留白/对齐/字距/克制——有没有一处廉价感)
2. 顶级设计师会认可交互习惯吗?(可见性/可控性/反馈/不劫持用户)
3. 够丝滑、能抓眼球吗?(六件套全开?有签名记忆点?有白屏/跳帧?)
4. 平庸吗?(框接框的堆砌=0分项;是否每章一个明确的戏剧动作)
5. 目标用户真会想这么看吗?(信息层级/讲解文字/时长可控/转化路径)
**硬性 0 分项(任一命中直接打回)**:框接框无叙事堆砌 / 元叙述文案 / 超过一种跳色 / 10秒翻完或不可控长卷 / 白屏闪帧 / 违反坑库任意一条。
**配套机器断言(质检官先看机器报告再打分)**:console 0 错、404=0、fps≥55、reduced-motion 退化可用、live 链接可点、契约色值白名单扫描通过。

## 三、工具箱速查(全部已在 qa-tools/ 与 base/ 落地,直接复用)
抽帧接触表 ffmpeg fps+tile / 视频剪辑压缩 -ss -t crf24 / base64解包正则 / docx抽文本 / puppeteer 逐章截图探针 probe-*.js / live站截图 capture-live.js / terser 混淆循环 / wrangler 增量部署 / prefetch 三板斧(真实预载loader+PRIORITY抢载+空闲全量预取)。

**开源/离线分发(2026-06-11 补)**
19. 根绝对路径(/showcase-assets/...)是 file:// 直开的杀手(会指向盘符根目录)——开源包内一律相对路径,或运行时按 location 解析(三环境统一一套代码);开源前必须做"file:// 直开"无头复现测试,不能只测 http。
20. iframe embed 的滚轮转发:父页不可达(file:// 跨源)时绝不能 preventDefault,否则 iframe 内滚动全死——先探测父句柄,拿不到就放行原生滚动。
21. 收件人会在压缩包里直接双击网页:index.html 必须带"样式未加载→解压指引"防呆;解压后 file 直开再叠一条"建议用启动器"可关闭横幅。外网 live 嵌入(github.io/hf.space)在 file 直开下可能被对方拒载,经启动器(localhost)则正常——属对方站策略,非缺素材。
