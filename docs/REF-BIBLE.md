## 一、全局拍板(各窗口不得擅改)

### 1. 跳色:正红(建议 #E32B16,印刷感正红)
- 黑白是展厅,红只活在**仪式与标记**上:开场幕、章节编号「0X」、光标信息卡描边、数字卡里的一个数字、波浪衔接段(可选)。
- **红永不做底色、永不进正文**。原片里的酸性黄/电紫/荧光绿/薄荷绿一律不带走。
- 展品规则:作品截图/演示视频内部的颜色是"内容",不受契约约束。**大面积多图区(格阵/素材河)默认 grayscale(1),hover 或滚动聚焦时恢复彩色**;单一焦点媒体(快闪秀框、通栏视频、918)保持原色。

### 2. 开场定稿(三个候选各取一段,串成一套,总时长约 4 秒)
1. **V7 的加载计数**:黑幕 + Space Mono 白数字真实预载(单调递增,不造假),文字 `mix-blend-mode:difference`;
2. **V9 的整幕上切**:计数到 100 → 红幕一闪、整体上切(全站唯一跳色的第一次亮相);
3. **V9/V10 的巨字逐字遮罩升起**:hero 口号 `说一句话。/ 拿到成品。` SplitText chars,yPercent 110→0,stagger 0.035;
4. **V3 的睁眼幕**降级为**全站章节切换的统一过场**(黑幕闭眼→白幕睁眼,约 1.4s),不再做进站开场。

### 3. 字体
- 英文/数字显示体 Archivo 900(负字距 -.04em),标签 Space Mono(.18em 大写);中文显示体 Noto Sans SC 900,中文正文 Noto Sans SC 400。全站只此三款。

### 4. 动效统一语言(防"效果杂烩")
- 滚动基建:**Lenis(lerp≈0.1)+ GSAP ScrollTrigger**,全站唯一缓动 `cubic-bezier(.16,1,.3,1)`,一切动画只动 transform/opacity。
- 文字进场只准用一个工具函数 `revealText(el,{mode})`,三种模式:`rise`(行级遮罩升起,V10)/`drop`(逐字掉落,V5,术语 staggered character drop-in)/`roll`(字符纵滚,V5,术语 masked vertical character roll / slot-machine roll)。标题用 rise,Hero 与章节卡用 drop,清单行用 roll。
- 章节切换只准用两种:黑白幕硬切(加 0X 章节卡)/ 睁眼幕(大章)。唯一软转场=波浪(V4),只出现一次。
- 必须支持 prefers-reduced-motion。

### 5. 沉浸式规格(铁律,上一版 10 秒翻完被批)
- 每个主章 ≥300vh 滚动行程,签名段必须 pin+scrub;全站总行程 ≈3500vh,匀速通读 75–110 秒。
- 每章节奏:章节卡半屏停留 → 签名效果 → 统一语言的内容段 → 切章仪式。

### 6. 砍单(明确不做/降级 P2)
不做:V6 OS窗口外壳、3D金属字、翻卡 deck、香蕉墙纸、Elvis 四人段。
P2(主线完成后再说):旋转方块滚筒(用户原话"或不弄也行")、可拖拽贴纸、V4 相册叠页(并入混合分栏)、手风琴清单、V1 叠层deck(用户指定备份)。

## 三、用户问题的正式回答

1. **掉落字术语**(V5):staggered character drop-in(SplitText per-char stagger,亦称 falling letters / cascading text reveal)。不是 split-flap、不是 scramble。
2. **MULTI MEDIA 翻滚术语**(V5):masked vertical character roll(slot-machine / odometer-style text roll)——字符在 overflow:hidden 行罩内纵向滚动,stagger 极密产生频闪感。放置位置:能力清单段(02章格阵标题/行进场)最合适。
3. **V11 创业网站怎么用**:它其实是哥伦比亚开发者 jorgetoloza.co 的个人作品档案页——版式与我们同构。两用:主用法=05章「素材河」;反向用法=06终幕字母汇聚作全站句点。不建议当 footer(浪费它的滚动行程)。
4. **开场三选一**:不选一,各取所长串成一套(见全局拍板 2)。
5. **流畅度的配方**(V2 核心诉求):Lenis 惯性滚动(最大来源)+ mask reveal(clip-path inset)+ scale settle + 长缓动 expo.out + 只动 transform/opacity(GPU 合成)+ scrub:1 的一秒平滑追赶。这六件套写进全局组件库,所有窗口直接调用。
