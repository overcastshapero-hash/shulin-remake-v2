## 二、技能章大改(窗口 C 执行,推翻原任务卡C的幕一幕二)

**保留**:16 卡物理掉落(用户原话"蛮惊喜")。
**整改**:
1. **卡片正面一律中文**:正面=中文技能名大字(Noto Sans SC 900,如`一键建站`/`口播成片`/`整本写真`/`整首成歌`)+中文一句话小字;**翻转背面才是英文包名**(make-website 等,Space Mono)。老板不认英文,中文是第一可视层。
2. **点击跳转**:每张卡可点击 → 滚动锚到该技能的格阵单元格(或浮层详情:中文名/输入→输出/一个真实成品缩略,有演示视频的挂视频)。
3. **格阵重做**:红巨字`技能`只作开章一拍(进场后缩小退到眉标位),**不准长期遮挡格子**(现状:巨字压住一半内容,画面乱)。格子以中文名为主(大),英文包名为辅(小灰),hover 浮出对应成品缩略。
4. **删掉宣言四屏**(与写真章、作品章内容重复——"一句话一整本写真"前面已经做过了,用户原话);技能章瘦身为:掉落开章 → 中文格阵 → 数据三件套分屏。砍内容换呼吸感,这是治"紧凑干巴"的根本。
5. **分屏右栏加大加料**(现状"苍白、字小、单调"):中文标题升到 clamp(2.2rem,4vw,3.4rem),正文 1.05rem;每屏必须有一行 mono 数据行(`抓取 127 篇 → 选题 9 个方向`式)+一个红色编号;左右栏宽比 7:5,右栏内容三段式(标题/一句话/数据行),不许只有两行小字。
6. **文案删改**:删`第十六个包,是用来造新包的`(用户:莫名其妙);skill-creator 卡面改为`造新技能 · 缺什么,造什么`。
7. 小红书爬取演示的首帧字丑 → 视频用 ffmpeg 掐掉前 1–2 秒再入站(素材在 operationbookbook\assets\videos\,可让总装窗口代剪)。

## 五、节奏令(全站,治"慢"和"干巴")

1. **删重复优先于拉长度**:同一能力全站只深讲一次(写真=01章,网站=02章,视频=03章,技能=06章只做索引不重演)。
2. scrub 行程统一砍 30%:格阵/分屏类 pin 从 300vh 降到 200vh;入场动画时长 ≤0.9s;Lenis lerp 0.1→0.12(跟手更快)。
3. 每章信息密度自查:一屏只说一件事,但**那件事必须占满那一屏的气场**(大字、大图、留白三选二),不许小字干巴堆角落。

## 六、为什么会"虎头蛇尾"(给用户的说明,窗口不用读)
执行窗口上下文越写越满,后半段质量衰减是真实现象。对策:① 一章一窗口,章内不超过 3 个大段;② 修订单逐条贴回,要求窗口"只改列出的条目,别的不许动";③ 每章交付后总装窗口立即验收,不攒批。
