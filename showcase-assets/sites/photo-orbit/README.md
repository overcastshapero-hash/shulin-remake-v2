# AI PORTRAIT ARCHIVE® — 3D 影像档案穹顶 (v4)

OpenPurpose® 式 3D 球面作品墙。相机位于球心，331 张作品全量贴在内球面；
球感来自广角镜头（fov 72/竖屏 80）+ 贴近的球壳（R=42）。
页面结构：黑色章节幕（模拟上一屏，红色 01 编号）→ 穹顶（sticky 钉在 260vh 区间内，
滚动进度驱动「俯角+旋转+广角 → 归位」的 3D 入场扫摆）→ 黑色液态波浪 → 极简版权带。
穹顶常态缓慢自转（纯水平 ≈1°/s，悬停/拖拽时平滑暂停）——既提示可交互，又不致眩晕。

## 启动

双击 `启动网站.bat`（需要 Python），浏览器自动打开 `http://localhost:8341`。
必须走 http（file:// 打不开 ES Module）。

## 交互

| 操作 | 效果 |
|---|---|
| 从章节幕下滑 | 穹顶以俯角+旋转+广角姿态进入，随滚动扫摆归位（球体感一眼可见） |
| （无需点击） | 贴图加载到 45% 自动飞入成球；黑球只做锚点 |
| 拖拽 | 旋转视角带惯性；鼠标移动有微视差 |
| 静止时 | 常态缓慢自转（纯水平 ≈1°/s），悬停/拖拽平滑暂停，松手缓升恢复 |
| 悬停卡片 | 0.2s 快速上浮 + 灰色光晕 |
| 点击卡片 | 瞬时 FLIP 展开（缩略图先显、高清图淡入），←/→ 翻阅，Esc 关闭 |
| ALL / SHE / HE | 按性别全量重排（女 221 / 男 110） |
| 点击黑球 | 切换环游模式（快速自转） |
| 继续下滑 | 黑色液态波浪（滚动越快涌动越大）→ 极简版权带 |

竖屏自动切换布局：fov 80、纬度 ±78°、行数更多，保住密度与弧度；触摸横滑转穹顶、竖滑翻页。
`prefers-reduced-motion` 时关闭自转与入场扫摆。

## 结构

- `index.html` / `app.js` — 页面与全部逻辑（无构建步骤）
- `vendor/` — 本地 three.js r170 + GSAP 3.12（离线可用）
- `assets/thumbs|large/` — 420px 缩略图（运行时压至 256 控显存）/ 1400px 大图
- `data/manifest.json` — 331 条 `{id, g, w, h}`
- `tools/process-images.ps1` — 从 `E:\Workspaces\社群资料库\photos\` 重新生成资产

## 调参速查（手感相关）

- 拖拽灵敏度 `k = 0.0024`、惯性衰减 `0.93`（app.js pointermove/tick）
- 常态自转 `0.00030`（≈1°/s，autoRamp 缓升缓停）、环游 `0.0012`
- 穹顶半径 `RADIUS = 42`、镜头 `fov 72`（竖屏 `80`）——球感的两个来源
- 卡片基准尺寸 `base` 下限 `6.0`（computeLayout；v1=5.4、v3=6.5，当前取中）
- 入场扫摆幅度：`entranceOffsets()` 里 `yaw 0.9 / pitch -0.34 / fov +12`，进度 60% 处完成；
  进度从穹顶露出第一像素起连续推进（不等钉住），顶部黑色 `#veil` 在进度 32% 内淡出（黑接黑过渡）
- 钉住时长：`#dome-wrap` 高度 `260vh`（CSS）
- 波浪振幅 `A1=16 + scrollBoost`（drawWave）
